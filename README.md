# ATP Tour Performance Analysis (2000–Present)

This project analyzes ATP Tour match data (2000–present) to evaluate and model player performance across different court surfaces.

It includes an interpretable Jupyter Notebook that:
- Tracks player Elo ratings over time  
- Segments performance by surface (hard, clay, grass)  
- Visualizes rating trends and key performance indicators  
- Explores machine learning approaches to predict match outcomes  

The goal is to combine transparent statistical modeling (Elo-based systems) with data-driven insights into surface specialization and competitive dynamics in professional tennis.
